Full-Screen Top-Down Navigation

Click on the "☰" button at the top to open the full-screen navigation that slides down from the top. The navigation now takes up 90% of the screen width and appears like a new page overlay.

The menu trigger button is automatically hidden when the navigation is open, and you can close it using the × button in the top-right corner of the navigation.

Enhanced features include:

• Full-screen navigation experience

• Slides down from top to bottom

• Takes up 90% of screen width

• Menu trigger button hides when navigation is open

• Close button positioned in top-right corner

• Smooth animations with staggered menu item entrance

• Fully responsive design optimized for all devices

• Improved accessibility with keyboard navigation support
